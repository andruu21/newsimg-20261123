Sum up 23 November's world news in one image. A newspaper front page rendered
entirely in code (Pillow, 4x supersample): 3 hero stories with vector art,
a stat band, a story row, an also-today list and a day-at-a-glance panel —
every story from verified 23 Nov 2026 headlines (BBC World, Al Jazeera,
Guardian), with outlet attributions. Deterministic: two runs produce
byte-identical `entry.png` (1024x1024, <1 MiB).

## Run it

```sh
python3 main.py
```
